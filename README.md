# 🎬 Movie Recommender System

A simple and interactive **Movie Recommender System** built with **Python** and **Streamlit**. This project recommends similar movies based on the selected title using content-based filtering.

## 🚀 Features

- 🔍 Content-based recommendation using movie metadata
- 🎥 Displays movie posters with titles
- 🧠 Utilizes cosine similarity for recommendations
- 🌐 Interactive web interface with Streamlit
- 📦 Lightweight and easy to deploy

## 🛠️ Tech Stack

- **Python**
- **Pandas / NumPy**
- **Scikit-learn** for vectorization and similarity
- **Streamlit** for web app UI
- **TMDb API** (for fetching posters)
